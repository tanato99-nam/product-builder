Google Gemini API 키 발급 방법 완벽 가이드

AI 헤어스타일 변환기를 사용하기 위한 Gemini API 키를 단계별로 발급받는 방법을 안내합니다.

API 키란 무엇인가요?

API 키(API Key)는 특정 소프트웨어 서비스에 접근하기 위한 고유한 인증 코드입니다. 마치 아파트 출입을 위한 열쇠 카드처럼, API 키를 가진 사람만이 해당 서비스의 기능을 사용할 수 있습니다. Google Gemini API 키는 Google의 인공지능 모델인 Gemini를 사용하기 위한 인증 코드입니다.

AI 도구 모음의 AI 헤어스타일 변환기는 Google Gemini AI 모델을 이용하여 이미지를 처리합니다. 이 AI 기능을 사용하기 위해서는 Google로부터 API 키를 발급받아야 합니다. 다행히 Google은 개인 사용자를 위한 무료 사용 한도를 넉넉하게 제공하고 있어, 일반적인 개인 사용자라면 별도 비용 없이 충분히 사용할 수 있습니다.

중요: API 키는 비밀번호와 마찬가지로 타인에게 공유하거나 공개 장소에 게시해서는 안 됩니다. AI 도구 모음은 사용자의 API 키를 브라우저 로컬 스토리지에만 저장하며, 저희 서버로는 전송하지 않습니다.

Gemini API 무료 사용 한도 (2026년 기준)

Google Gemini API는 개인 개발자와 일반 사용자를 위한 무료 사용 티어(Free Tier)를 제공합니다. 무료 티어에서는 매월 일정 한도 내에서 API를 무료로 사용할 수 있습니다. 아래 표는 주요 모델별 무료 한도를 정리한 것입니다.

모델 분당 요청 (RPM) 일일 요청 (RPD) 요금
Gemini 2.0 Flash 15 RPM 1,500 RPD 무료
Gemini 2.0 Flash-Lite 30 RPM 1,500 RPD 무료
Gemini 1.5 Pro 2 RPM 50 RPD 무료
Gemini 1.5 Flash 15 RPM 1,500 RPD 무료

RPM(Requests Per Minute)은 분당 처리 가능한 최대 요청 수를, RPD(Requests Per Day)는 하루 처리 가능한 최대 요청 수를 의미합니다. AI 헤어스타일 변환기 1회 실행 시 1개의 요청이 사용됩니다. 즉, Gemini 2.0 Flash 기준으로 하루 최대 1,500번 헤어스타일을 변환할 수 있으며, 일반적인 개인 사용에는 충분하고도 남습니다.

꿀팁: 무료 사용 한도를 초과할 경우, 잠시 기다렸다가 다시 시도하면 됩니다. 분당 한도를 초과한 경우 1분 후, 일일 한도를 초과한 경우 다음 날 다시 사용할 수 있습니다.

Gemini API 키 발급 7단계 가이드

아래 7단계를 따라 천천히 진행하시면 5분 이내에 API 키를 발급받으실 수 있습니다.

1

Google 계정 준비하기

Gemini API 키를 발급받으려면 Google 계정이 필요합니다. Gmail 주소가 있다면 그 계정을 그대로 사용하시면 됩니다. Google 계정이 없다면 accounts.google.com에 접속하여 무료로 만들 수 있습니다. 기존에 사용하시던 Google 계정(Gmail, YouTube, Google Drive 등)을 그대로 이용하실 수 있으니 대부분 이 단계는 건너뛰어도 됩니다.

2

Google AI Studio 접속하기

인터넷 브라우저(Chrome 권장)를 열고 주소창에 aistudio.google.com을 입력하고 Enter를 누릅니다. Google AI Studio는 Gemini API를 포함한 Google의 AI 개발 도구를 제공하는 공식 플랫폼입니다. 처음 접속하시는 분들은 영어로 된 화면이 나타납니다. 한국어로 변경하려면 우측 하단의 언어 설정에서 '한국어'를 선택하실 수 있습니다.

3

Google 계정으로 로그인하기

Google AI Studio 페이지에서 Sign in 버튼을 클릭하거나, 이미 로그인된 상태라면 자동으로 메인 화면이 표시됩니다. 로그인 버튼을 클릭하면 Google 계정 선택 화면이 나타납니다. 사용하실 Google 계정을 선택하시거나, 계정 이메일과 비밀번호를 입력하여 로그인합니다. 처음 접속 시 Google AI Studio 이용약관에 동의하는 화면이 나타날 수 있습니다. 약관을 확인한 후 동의 버튼을 클릭하세요.

4

API 키 발급 메뉴로 이동하기

로그인 후 메인 화면에서 왼쪽 사이드바 메뉴를 확인합니다. 메뉴 목록 중에서 Get API key 또는 API 키 가져오기를 클릭합니다. 만약 사이드바가 보이지 않는다면, 좌측 상단의 햄버거 메뉴(세 줄 아이콘)를 클릭하면 메뉴가 펼쳐집니다. 해당 메뉴를 클릭하면 API 키 관리 페이지로 이동합니다.

5

새 API 키 생성하기

API 키 관리 페이지에서 Create API key 버튼을 클릭합니다. 버튼은 보통 파란색 또는 보라색으로 눈에 잘 띄게 표시되어 있습니다. 버튼을 클릭하면 프로젝트 선택 다이얼로그가 나타납니다. 처음 이용하시는 분이라면 Create API key in new project를 선택하시는 것을 권장합니다. 이미 Google Cloud 프로젝트가 있으신 분은 기존 프로젝트를 선택해도 됩니다.

6

프로젝트 이름 설정 (선택사항)

새 프로젝트를 만드는 경우, 프로젝트 이름을 입력하는 화면이 나타날 수 있습니다. 개인 사용 목적이라면 My AI Project나 Personal과 같이 알아보기 쉬운 이름을 입력하세요. 프로젝트 이름은 나중에 변경할 수 있으니 크게 신경 쓰지 않아도 됩니다. 이름을 입력한 후 Create 또는 생성 버튼을 클릭합니다.

7

API 키 복사 및 안전하게 저장하기

잠시 후 AIza로 시작하는 긴 문자열 형태의 API 키가 생성되어 화면에 표시됩니다. 복사 아이콘이나 Copy 버튼을 클릭하여 API 키를 복사합니다. 이 키는 나중에 다시 확인할 수 있으나, 보안상 이유로 처음 생성 시에만 전체 키를 볼 수 있는 경우가 있으므로, 복사하여 안전한 곳(메모장, 비밀번호 관리 앱 등)에 저장해 두는 것을 권장합니다. 복사한 API 키를 AI 도구 모음의 헤어스타일 변환기 입력란에 붙여넣으시면 됩니다.

AI 도구 모음에서 API 키 사용하는 방법

발급받은 Gemini API 키를 AI 도구 모음의 AI 헤어스타일 변환기에 등록하는 방법은 매우 간단합니다.

1단계: AI 헤어스타일 변환기 페이지로 이동합니다.

2단계: 페이지 상단에 있는 "Gemini API 키 입력" 입력란을 찾아 클릭합니다.

3단계: 발급받은 API 키(AIza...로 시작하는 키)를 붙여넣습니다.

4단계: "저장" 버튼을 클릭합니다. API 키는 브라우저 로컬 스토리지에 저장되어, 다음에 방문할 때 다시 입력할 필요가 없습니다.

5단계: 이제 내 사진과 원하는 헤어스타일 사진을 업로드하고 "헤어스타일 변환" 버튼을 클릭하면 AI가 헤어스타일을 변환해줍니다.

보안 팁: 다른 사람의 기기에서 사용하셨다면, 사용 후 반드시 API 키를 삭제하거나 브라우저 로컬 데이터를 지워주세요. API 키가 노출되면 타인이 귀하의 사용 한도를 소비할 수 있습니다.

API 키 보안 주의사항

API 키는 마치 은행 비밀번호와 같습니다. 노출되면 타인이 내 할당량을 사용하거나, 유료 사용자의 경우 요금이 부과될 수 있으므로 다음 보안 수칙을 반드시 지켜주세요.

절대 하지 말아야 할 것들:

- GitHub, GitLab, Bitbucket 등 공개 저장소에 API 키를 업로드하지 마세요.
- 카카오톡, 라인, 디스코드, 슬랙 등 메신저를 통해 API 키를 공유하지 마세요.
- 블로그 포스트나 SNS에 API 키를 게시하지 마세요.
- 이메일 본문에 API 키를 포함시켜 전송하지 마세요.
- 신뢰할 수 없는 제3자 서비스에 API 키를 입력하지 마세요.

만약 API 키가 유출되었다고 의심된다면, 즉시 Google AI Studio에 접속하여 해당 API 키를 삭제하고 새 키를 발급받으세요. API 키 관리 페이지에서 기존 키 옆의 삭제(Delete) 버튼을 클릭하면 즉시 해당 키의 사용이 중단됩니다. 그리고 새 API 키를 발급받아 사용하면 됩니다.

여러 서비스에서 Gemini API를 사용한다면, 각 서비스별로 별도의 API 키를 발급하여 사용하는 것을 권장합니다. 이렇게 하면 특정 서비스에서 문제가 발생했을 때 해당 키만 삭제하고 나머지 서비스는 계속 사용할 수 있습니다.

API 관련 오류 해결 방법

AI 헤어스타일 변환기 사용 중 오류가 발생하는 경우, 아래 목록에서 해당 오류를 확인하고 해결 방법을 따라해보세요.

400 Bad Request / INVALID_ARGUMENT

잘못된 API 키 형식

입력한 API 키 형식이 올바르지 않을 때 발생합니다. API 키는 반드시 "AIza"로 시작하는 39자리 문자열이어야 합니다. 복사 시 공백이나 불필요한 문자가 포함되지 않았는지 확인하세요. API 키 입력란의 내용을 지우고 다시 붙여넣어 보세요.

403 Forbidden / API_KEY_INVALID

유효하지 않거나 삭제된 API 키

입력한 API 키가 존재하지 않거나 이미 삭제된 경우에 발생합니다. Google AI Studio에 접속하여 API 키가 아직 유효한지 확인하세요. 키가 삭제되었다면 새 API 키를 발급받아 다시 입력하세요.

429 Too Many Requests / RESOURCE_EXHAUSTED

사용 한도 초과

분당 또는 일일 무료 사용 한도를 초과했을 때 발생합니다. 분당 한도(RPM)를 초과한 경우 1~2분 기다렸다가 다시 시도하세요. 일일 한도(RPD)를 초과한 경우 다음 날(한국 시간 오전 9시 이후)에 다시 시도하세요. 잦은 사용이 필요하다면 Google AI Studio에서 유료 플랜으로 업그레이드를 고려해보세요.

500 Internal Server Error

Google AI 서버 일시 오류

Google Gemini API 서버에 일시적인 문제가 발생한 경우입니다. 사용자 측의 문제가 아니므로 잠시 기다렸다가(보통 5~10분) 다시 시도하세요. 반복적으로 발생한다면 Google AI 상태 페이지(status.cloud.google.com)에서 서비스 상태를 확인해보세요.

이미지 처리 오류 / 변환 실패

이미지 파일 문제

업로드한 이미지 파일이 너무 크거나, 지원하지 않는 형식인 경우 오류가 발생할 수 있습니다. JPG, PNG, WebP 형식의 10MB 이하 이미지를 사용하는 것을 권장합니다. 이미지 파일을 다시 확인하고, 필요하다면 이미지 크기를 줄여서 다시 시도해보세요.

자주 묻는 질문

Gemini API 키 발급과 관련해 많이 묻는 질문들을 모았습니다.

네, Google AI Studio(aistudio.google.com)에서 Google 계정으로 로그인하면 완전 무료로 Gemini API 키를 발급받을 수 있습니다. 신용카드나 결제 정보 입력 없이 Google 계정만 있으면 됩니다. 발급받은 API 키로 일정 한도 내에서 Gemini API를 무료로 사용할 수 있습니다. 2026년 기준 Gemini 2.0 Flash 모델은 분당 15회, 하루 1,500회 요청이 무료 제공됩니다.
네, 하나의 Google 계정으로 여러 개의 API 키를 발급받을 수 있습니다. 다만 각 키의 무료 사용 한도는 동일하며, 프로젝트 단위로 관리됩니다. 여러 서비스에서 각각 다른 API 키를 사용하면 보안 관리가 용이합니다. 특정 키가 유출되어도 해당 키만 삭제하면 되기 때문입니다.
기본적으로 Gemini API 키는 만료 기간이 없습니다. 단, 90일 이상 사용되지 않은 경우 Google이 자동으로 삭제할 수 있습니다. 또한 Google의 정책 변경에 따라 API 동작이나 한도가 변경될 수 있습니다. 키가 갑자기 작동하지 않는다면 Google AI Studio에서 키 상태를 확인해보세요.
AI 도구 모음은 사용자가 입력한 API 키를 브라우저의 로컬 스토리지에만 저장합니다. 이 키는 절대 AI 도구 모음의 서버로 전송되지 않습니다. API 요청은 사용자의 브라우저에서 직접 Google Gemini API 서버로 전송됩니다. 저희는 키를 볼 수 없고, 저장하지도 않습니다. 다만, 다른 사람의 기기에서 사용했다면 브라우저 로컬 데이터를 삭제하는 것을 권장합니다.
무료 사용 한도(RPM 또는 RPD)를 초과하면 429 오류가 발생하며 요청이 처리되지 않습니다. 분당 한도를 초과한 경우 1~2분 기다렸다가 다시 시도하면 됩니다. 일일 한도를 초과한 경우 다음 날까지 기다려야 합니다. 한도 초과 시 자동으로 요금이 청구되지는 않으며, 유료 사용을 원하신다면 Google Cloud Console에서 결제를 설정하고 유료 티어로 업그레이드해야 합니다.
Google AI Studio(aistudio.google.com)에 접속하여 로그인한 후, 좌측 메뉴에서 "API Keys" 또는 "Get API key"를 클릭하면 기존에 발급받은 API 키 목록을 확인할 수 있습니다. 보안상 이유로 키 전체 내용이 표시되지 않을 수 있는데, 이 경우 기존 키를 삭제하고 새 API 키를 발급받으세요. 새 키를 발급받는 데 걸리는 시간은 1분 이내입니다.
